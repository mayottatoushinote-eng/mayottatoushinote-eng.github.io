データの取り扱い

プライバシーポリシー

この文書は、MAYOTTA Creator Intelligence CoreによるYouTubeデータの収集・保存・分析について説明します。

1. 対象と目的

管理対象のチャンネルの運用状況を確認し、公開動画の比較と分析記録の保全に使います。現在は運営者本人による個人利用が対象です。

2. アクセスする情報

  • チャンネルと動画のID、タイトル、説明、公開時刻、公開状態、動画の長さ、サムネイルURLなどの動画情報。
  • 公開されている再生数などの指標と、公式APIで取得できる公開コメント。コメント取得が拒否された場合は本文を補いません。
  • 認可された管理対象チャンネルのYouTube Analytics・Reporting APIの集計データ。再生数、視聴時間、視聴維持、端末・地域など、利用可能な範囲の集計を含みます。
  • API接続に必要なOAuth認証情報と、取得時点・取得結果・エラーなどの運用記録。

GoogleパスワードはGoogleの認証画面で扱われ、このアプリの入力項目には含まれません。

3. 保存とアクセス

観測データと履歴は、運営者が管理する非公開GitHubリポジトリに保存します。分析・確認のためにローカルファイルを利用することもあります。OAuth更新トークンなどはGitHub Actions Secretsとして保管し、公開サイトや公開資料には含めません。

実行環境としてGitHub Actions、API接続先としてGoogleのサービスを利用します。運営者が個別に指示・承認した分析のため、集計結果などをChatGPT・Codex等の分析支援サービスで扱うことがあります。それぞれのサービスにおける取り扱いは、そのサービスの規約・プライバシー通知が適用されます。

4. 利用の範囲

Google APIから得た情報の利用・移転は、Limited Use（限定的な利用）を含むGoogle API Services User Data Policyに従います。アプリの目的であるチャンネルの運用分析と、そのために明示承認された分析支援に用途を限定します。

このサイトに、OAuth認証情報、収集した非公開指標、収集データ本体を公開する機能はありません。

5. 履歴の保全と認可の撤回

時点別の分析に使うため、取得履歴を保存します。現在、観測履歴を一定の日数で自動削除する機能は設定していません。認可の撤回、保存データの確認・削除については、下記の連絡先へお問い合わせください。

Googleアカウントの接続設定から、このアプリへの認可を撤回できます。

6. この案内サイト

案内サイトに独自の広告、訪問解析、入力フォーム、アプリによるCookie設定は設けません。公開にGitHub Pagesを使う場合、GitHubはセキュリティ目的で訪問者のIPアドレス等を記録します。詳しくはGitHubのプライバシー声明をご覧ください。
